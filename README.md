# Desafio-7DaysOfCode-
Repositório criado para acompanhar minha jornada no desafio #7DaysOfCode da Alura, com foco no aprendizado e na prática de Git e Git Hub.
Durante o desafio, vou praticar conceitos como: 
Git e controle de versão; Git Hub e repositórios; Commits; Branches; Merge; Pull Requests; Colaboração em projetos; Boas práticas com Git e GitHub.

Tecnologias e ferramentas: 
Git; GitHub; Markdown
